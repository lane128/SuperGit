# C2 · 以 C 为基础的收敛版

C 的三栏、24px 行、深色和 45° 线图保留。这一版不再往界面上加面板，而是把重复的状态、常驻的危险操作和分散的功能收回原位，并补上真正会影响使用的交互状态。

先看：

- `C2-workspace.png`：工作区
- `C2-history.png`：历史
- `C2-details.png`：文件行、部分暂存、提交校验、危险确认、命令面板、子模块与撤销
- `C2L-workspace-zh.png`、`C2L-workspace-en.png`、`C2L-history-zh.png`、`C2L-history-en.png`：日光模式与中英文

## 这次改了什么

### 减少常驻元素

- 去掉整条页面标题栏。工作区标题和改动数放进文件列头部，历史标题和筛选并进同一条工具栏。
- 删除左侧「工作区状态」表、「最近操作」和底部常驻「丢弃全部改动」。
- 删除右侧「Git 状态」「同步」「危险操作」「最近提交」四块。右侧只保留提交表单。
- 顶栏只留仓库名、分支切换、ahead/behind、搜索/命令、同步下拉和应用菜单。
- 轨道从 7 个入口收成 5 个：工作区、历史、子模块、分支、更多；Stash、Worktrees、冲突处理放进「更多」。

### 功能归位

- 底部状态条成为唯一状态来源：HEAD、Index、Worktree、ahead/behind、上游、同步时间和编码。
- 左列：文件列表 + 当前选中文件的信息和动作。选中文件后不再需要去别处找路径、hunk 数或暂存入口。
- 中列：Diff 顶部用「改动 / 历史 2 / 信息」切换。文件历史和 Diff 设置不再各占一块。
- 右列：只做提交。消息、说明、本次提交摘要、提交按钮、折叠的提交选项、上次提交。
- Fetch / Pull / Push 收进顶栏「同步 ⌄」，不再占三个按钮。
- 危险操作用确认对话框，列出影响文件，默认不删除未跟踪文件。

### 细节与交互

- 文件行 24px：状态色脊 + 字母 + 名称 + 路径 + 类型；动作只在当前行出现。冲突行给「! + 解决」，子模块行给「子模块 · main ↑1」。
- 部分暂存：点击行号选择，Shift 连选，⌥↑↓ 扩展；选中后动作条只出现一次，「暂存 4 行」和「取消」在同一行。
- 提交校验：空说明时按钮禁用；hooks 运行时按钮内显示进度；失败时错误、查看输出、跳过 hooks 和重试都留在提交面板内。
- 键盘：⌘K 命令面板、⌘↩ 提交、空格暂存当前文件；命令面板里直接搜索「暂存 / Fetch / 切换分支」。
- 可撤销反馈：丢弃后给 5 秒撤销；提交后给「推送」下一步，不弹成功对话框。
- 子模块：指针变化 `a1b2c3 → d4e5f6`、`main ↑1 ↓0`、更新、打开子模块、暂存指针在同一张卡片里。

## C2L · 日光模式与中英文

日间模式沿用 C2 的三栏、24px 行、标签页和提交面板，只替换颜色与文案，不新增常驻控件。主题和语言入口留在设置里，顶栏仍保持仓库、分支、搜索、同步四组元素。

文件：

- `C2L-workspace-zh.png` / `C2L-workspace-en.png`
- `C2L-history-zh.png` / `C2L-history-en.png`

### 日光配色

- 外壳 `#e6ebf0`，内容面 `#ffffff`，悬浮面 `#f2f5f8`，边界 `#dde3e8`。
- 主文字 `#1a222b`，次要文字 `#4f5c68`，弱化文字 `#5f6b76`；弱化色在选中行和状态条上仍保持约 4.5:1。
- 强调色 `#0b6f9e`，选中 `#e2f0f8`；新增 `#e6f5ec`，删除 `#fdecec`，警告 `#8a5a00`，危险 `#b23a3a`。
- 颜色语义和深色版一致；状态不靠颜色单独表达，仍保留字母、文字和图标。

### 多语言布局

- 同一份数据、同一套组件，只切换字符串表；英文用单复数函数处理 `1 change / 4 changes`、`1 hunk / 1 hunk`。
- 文件列标题和改动数按标题宽度定位，避免 `Workspace` 比 `工作区` 长时挤压计数。
- Diff 标签页、统一/左右分段、部分暂存动作条都按文案宽度计算位置；英文的 `Stage 4 lines` 不再被 64px 按钮截断。
- 页脚英文省略 hunk 数，只保留 `4 additions · 1 deletion`，给 `Ignore whitespace` 和 `Context 3` 留出间距。
- 历史表把 SHA 列右移到 632，`Yesterday` 与 SHA 之间保留可读间距；时间、表头、详情面板和状态条都使用对应语言。
- `README.md` 的路径在中文里显示「项目根目录」，英文里显示 `Project root`；提交说明和代码保持原文。

## 复现

```bash
cd design/directions/c2
node generate.mjs   # 3 个深色 SVG
node render.mjs     # 3 个深色 PNG + check.json
node generate-light.mjs   # 4 个浅色/双语 SVG
node render-light.mjs     # 4 个浅色/双语 PNG + check-light.json
```

## 边界

- 静态 SVG，没有接入 MyGo 或 Go 后端。
- 没有修改 C 本身的 `c.mjs` 和 `C-*.png`，C2 是新目录，方便对照。
- 没有提交、推送或发布。
- 命令面板、撤销、hooks 进度、确认框都只是画面状态，尚未实现真实交互。
- 本轮日光与双语只覆盖工作区、历史两个主屏；`C2-details.png` 仍是深色交互说明页，未做浅色/英文版。
