# SuperGit 桌面精修稿

本轮保留已认可的功能布局，重新建立视觉语言、文字层级、列表锚点、控件和反馈规则。主交付仍是本地 PDF 与 SVG；没有新增网页入口，也没有改动原生应用。

- [精修审阅册](review.pdf)：25 页，优先查看规范、核心页面与交互状态。
- [完整逐页稿](roadmap.pdf)：51 页，目录 + 4 页规范 + 40 个工作流画板 + 6 个交互状态。
- [40 个页面状态的全景](roadmap.svg)。
- [6 个交互状态的全景](ux-states.svg)。

上一轮所有文件保留在 `../roadmap/`。本目录是独立的新稿，可直接比较。

## 本轮的视觉语言

导航使用墨紫色平面，集中表达仓库、子模块和当前工作区；主内容使用接近白色的阅读面。仓库页签、列表选中与品牌共同使用“成对边界包围一个对象”的标记，呼应 Index 与工作区各自独立的边界。

颜色只是其中一部分。本轮同时改变了导航分组、内容面的边界、文件列结构、对象属性、弹窗上下文区、底部操作区、提示的严重程度与焦点表达。

## 字体和间距

[字体与对齐规范 S1](S1.svg)是设计图，[控件与反馈 S2](S2.svg)、[列表与交互 S3](S3.svg)、[视觉身份与深浅色 S4](S4.svg)展示规则如何落到控件上。

| 角色 | 字号 / 行高 | 字重 | 用途 |
| --- | --- | --- | --- |
| 页面标题 | 20 / 28 | 600 | 页面、弹窗标题 |
| 分组标题 | 15 / 24 | 600 | 内容分组与局部结构 |
| 正文与操作 | 13 / 20 | 400 / 500 / 600 | 导航、文件名、表单、按钮、代码 |
| 辅助信息 | 11 / 16 | 400 / 500 | 路径、来源、行号、非关键元数据 |

界面字体：Helvetica Neue / PingFang SC。代码与需要对齐的 SHA 使用 Menlo / SF Mono。展示规范本身的大标题属于图稿注释，不属于软件字号。

- 间距基准 4px；主要间隔为 8 / 12 / 16 / 24px。
- 紧凑历史行 32px；常规单行 36px；名称与路径的双行文件项 48px。
- 子模块包含路径和状态，是独立的 72px 对象行。
- 常规按钮和输入框 32px；文件行内图标按钮命中区域为 28 × 28px。
- 图标 16px、1.5px 描边；图标与文字间隔 8px。
- 控件圆角 5px、选中 4px、窗口 12px、弹窗 14px。
- 文件名、路径共用左边界，状态与操作各自保留固定列。操作出现时不推动文件名。
- 选中标记表示对象归属；外圈表示键盘焦点，二者不会互相替代。

这些是本轮待评审的设计规范，尚未写入项目的长期约束文件。

## 实现边界

全部产物均为静态设计与状态说明。稿中可见的菜单、悬停、焦点、切换与运行状态是被画出的示例，不代表已实现交互原型或原生功能。

R1 表示对应底层 Git 能力已存在，R2 表示页签、多语言和完整设置等新增提案，R3 为后续能力。新视觉规范均未应用到 MyGo 客户端，也不构成发布日程。

## 源码与导出

- `primitives.mjs`：字体、颜色、尺寸、共同控件与窗口。
- `screens.mjs`：重画工作区、历史、子模块、仓库入口与关键状态。
- `inherited-screens.mjs`：其余工作流内容，全部通过新共同组件绘制。
- `catalog.mjs`：沿用页面清单，修正选行与暂存的状态边界，补充 U1–U6。
- `boards.mjs`：S1–S4 设计规范图。
- `generate.mjs`：SVG、前后对照、分区与 manifest。
- `render.mjs`：PNG / PDF 导出，检查字体 token、文字边界、动作标签、关键页面文字碰撞、文字对比度和外部请求。

运行 `node design/refinement/generate.mjs`，再运行 `node design/refinement/render.mjs`。渲染沿用会话内已有的隔离 Playwright 与本机 Chrome，不是原生应用运行依赖。
