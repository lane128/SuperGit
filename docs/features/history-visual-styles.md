# 历史 Graph 与引用标签可组合样式

Status: Approved
Date: 2026-11-25
Related: 本地第四轮设计预览 `design/history-style-preview.html`

## Background and goal

用户已完成预览筛选并要求实现：Graph 保留 R1/R2/R4，引用标签保留 A2/B1，两个维度均进入设置，可以独立选择、自由组合，重启后保留。视觉方向已由用户要求实现；本文补齐设置、兼容、渲染和验证设计。

可观察结果：三种 Graph × 两种标签共六种组合均可用；切换立即刷新历史显示，不需要重启或重新读取仓库；分支、远端、Tag、Stash 和 HEAD 可辨识；长名称仍可识别且可查看全文；连线直接到节点，无选中光圈造成的空隙。

## Non-goals

- 不改变提交拓扑、轨道分配、分页、折叠合并语义或 Git 写入操作。
- 不增加旧 Graph / 旧标签作为第四种、第三种选项。
- 不把历史标签偏好扩展到侧栏、提交详情或其他页面的通用标签。
- 不增加新设置页、独立预览窗口或额外开关，不引入外部依赖。

## Approach

### 设置与默认值

复用设置 → 历史的现有卡片及 `choiceRow` 控件，提供中英文文案：

- 历史图卡片：新增“连线样式”，选项“小圆角接点”（R1）、“柔化斜切”（R2）、“贴点短弯”（R4）；保留现有显示 Graph、线条粗细、节点大小。
- 历史列表卡片：新增“引用标签样式”，选项“双段胶囊”（A2）、“紧凑色签”（B1）；保留作者和时间设置。
- 默认采用 R1 + A2。旧配置缺少新字段时使用这组默认值；未知值也回退到对应默认值。恢复默认设置同时恢复这两个维度。
- 采用语义字符串键 `historyGraphStyle: rounded | chamfer | compact`、`historyRefStyle: segmented | stripe`，不复用现有仅表示线宽的 `historyLine`。
- 全局偏好应用于各仓库及复用该历史行渲染器的视图；切换标签不改变 Graph，切换 Graph 不改变标签。隐藏 Graph 时仍可选择和保存连线样式，标签继续正常显示。
- 复用原子写入和设置窗口错误提示。写入失败时本次运行仍应用选择，并明确提示不能保存；不新增成功提示遮挡错误。

### Graph 绘制

以预览的三种连接形状为依据，保留当前主题轨道颜色、线宽、节点尺寸、行高、横向平移和轨道分配。

- R1：节点侧面出入，以小圆角连接竖直轨道，标准尺寸半径约 8px。
- R2：短斜段在节点附近换道，斜段与竖线之间柔化转角，标准半径约 7px。
- R4：节点上下出入，在约 18px 范围完成短曲线换道，中间保持竖直。
- 半径／转向范围须受实际行高、轨道间距和端点距离限制，避免相邻行或窄轨道下回折；不将 HTML 的固定 44px 坐标直接用于应用。
- 对整条边定义一致几何，再按当前可见行区间采样或裁剪，确保跨行边界位置和切线连续。只计算可见片段，长边计算成本不随跨越行数增加，不物化全历史路径。
- 选中节点保留可辨识外环，移除遮断连线的外围不透明填充；节点自身内部背景填充仍保留。检查所有节点尺寸与线宽组合。
- 保持现有工作区虚线、Stash 语义、分页边界标记和合并折叠指示；不为复刻示例拓扑重写真实 Stash 父关系。

### 历史引用标签

沿用现有引用优先顺序、点击／右键菜单、tooltip 和折叠菜单逻辑，替换历史行专用绘制与测量。

- A2：紧凑双色分区，约 20px 图标区，HEAD 独立标记区，淡分隔线和中性文字；类别通过图标与轮廓辨识。
- B1：2px 左色条，中性背景和文字，HEAD 浅色强调；Stash 色条为实线。
- 两者以 20px 高度、11px 名称字号为标准，遵循应用字体缩放；大字体须保证文字与标记不裁切。
- 名称前缀弱化、末段优先保留，超长末段也必须截断；悬停展示未截断的名称。HEAD 显示标记与实际名称，仍由现有逻辑识别 attached/detached HEAD。
- 宽度预算必须计入样式自身的边框、图标／HEAD 区、分隔线、内边距和间距；测量与绘制共享尺寸来源。
- 窄窗口减少可见引用并显示准确 `+N`；HEAD 优先，在完全放不下的极窄预算下允许使用现有折叠菜单兜底，不能挤出行界。
- 溢出标签保持中性；切换样式与窗口缩放后菜单键仍绑定真实引用，避免对错误分支执行菜单操作。
- 预算连 `+N` 都不足时，优先把完整溢出标签移到标题行并缩短标题；若行内容区域仍不足，则约束／裁剪在行内，保留行上下文菜单中的引用入口供键盘和右键访问，不创建越界命中区。测试实际布局边界与菜单可达性，而不只检查引用数量。
- Stash 当前在 `historyEntryRow` 中绕过普通 refs，经 `stashBadge` 独立绘制。显式接入历史专用 Stash 样式路径，显示 `stash@{n}`、保留原 tooltip 和行交互；不修改无关页面的通用 warning Tag。复用 `historyEntryRow` 的独立 Stash 列表同样应用偏好。
- 使用现有主题 token、轨道配色和对比度工具；浅／深主题中主文本和弱化前缀对各自背景均达到 4.5:1。参考 HTML 中的固定示例颜色不替换产品主题。

预览：`design/history-style-preview.html`（本地 gitignored 文件，第四轮）。设置布局复用现有控件，不新做整页视觉设计。

## Alternatives and trade-offs

- 不把六种组合做成六个预设：两个独立选择更容易理解，也保留现有线宽／节点设置。
- 不复用 `historyLine` 保存路径类型：该字段目前表示线宽，复用会破坏旧偏好。
- 限定新标签渲染到历史行，避免共享 `refPill` 的其他调用点产生未经请求的视觉变化。
- 原有轨道配色优先于示例配色；路径、分区、边界、密度保持预览方向。

## Impact

- `internal/lobedesk/app.go`：两个全局显示偏好。
- `settings.go`：字段、默认值、归一化、读取／保存、恢复默认。
- `settings_page.go`、`i18n.go`：两组独立选项和中英文文案。
- `graph.go` 或独立 `history_graph_style.go`：可见区路径几何。
- `history.go`：调用样式几何，修正选中环遮线，接入 Stash 独立标签路径；按调用范围需要调整 `stash.go` 的历史专用入口。
- `history_row_refs.go`、独立 `history_ref_style.go`：历史专用标签绘制与宽度测量；仅按需要复用 `ref_capsule.go` 颜色工具。
- 直接相关的设置、Graph、标签布局及 UI 测试；不更改 Git 数据层。
- 兼容性：新增 JSON 字段、无版本迁移；旧值保留。旧二进制忽略新字段，旧二进制再次保存可能丢弃新偏好，回滚不影响仓库数据。
- 不涉及签名、权限、密钥或删除用户内容。

## Test plan

先写失败测试，再实施。所有测试使用隔离配置目录及仓库。

- 设置：三种与两种键归一化、缺失／非法值、JSON round trip、六种组合互不覆盖、reset、写入失败反馈；旧 `historyLine` / `historyNode` 值仍有效。
- Graph：三种路径左右换道、同轨、相邻节点、长跨度、via lane 与两端不同、边界裁剪拼接、单侧无换道、异常空区间；端点精确匹配且中段竖直。
- 绘制回归：选中普通／HEAD／合并／Stash 节点无外围遮线；小／标准／大节点与细／标准／粗线组合；合并折叠、工作区虚线和边界标记不回归。
- 几何补充：作者／时间同时隐藏（单行标题）和 metadata 可见（双行）两种实际行高；15px 压缩轨道间距；fork 菱形节点与选择环。
- 对比度：数值断言两款主文本、弱化前缀在普通／hover／selected 背景、浅深主题下均达到 4.5:1。
- 性能：可见片段点数有上界，跨度增长不产生线性采样；运行相关现有 graph 性能测试。
- 标签：两款的真实测量预算，HEAD 优先、长远端路径／中文／Unicode、超长无斜杠名称、多引用准确计数、极窄预算、字体缩放；菜单与 tooltip 保持正确引用。
- UI：两组选择真实交互并独立保存；中英文、Graph 隐藏状态；现有行选择／焦点／菜单回归测试。
- 验证命令：gofmt、go vet、在无 build fixture 的隔离 worktree 运行一次 `go test -cover ./...`；不再背靠背运行 `make test`。本次不涉及跨包／底层构建，不额外跑 `make check`。
- 代码完成后独立只读审查，仅检查 diff 和直接相关文件，不重跑测试；先解决问题再实机验收。

## Acceptance steps

1. 实现使用隔离 worktree，携带本地预览作为视觉参考。测试完成后运行 `make e2e-build`，再以 `GOFLAGS=-tags=e2e make app` 构建 `build/SuperGit.app`；使用 `SUPERGIT_TEST_CONFIG_DIR` 指向临时配置目录，并启用 `MYGO_AUTOMATION`，直接启动该 bundle 的可执行文件传入测试仓库。此配置隔离钩子只在 e2e 构建存在，不在普通构建上误用；不改写 HOME，不替换 `/Applications` 下安装版。最后另行确认普通 `make app` 构建成功。
2. 测试仓库包含本地分支、远端引用、Tag、Stash、HEAD、普通／合并提交、长名称和多引用；设置中逐一选择六种组合，确认历史列表立即改变，当前提交和滚动位置保持。
3. 保存组合、退出重开，确认恢复；更换仓库仍采用同一全局组合；恢复默认后为 R1 + A2。
4. 浅／深主题，在 360／600／900px 历史列表宽度附近及设置窄／宽窗口检查；字体小／标准／大，中英文文案不裁切，图形跨行不断裂；至少保存六组合截图，并补浅深／窄宽重点截图。
5. 选择节点、滚动跨行、平移多轨道 Graph、折叠合并、打开引用和 `+N` 菜单、检查 tooltip；隐藏 Graph 后标签仍可切换；重新显示 Graph 后选择仍生效。
6. 使用隔离配置验证保存失败提示：在测试应用完成读取后，将临时配置中的 `supergit/settings.json` 路径替换为同名目录，触发原子重命名失败；切换样式应在当前运行生效且显示持续警告，重启不声称保存成功。仅处理本次创建的 fixture，不修改用户真实配置权限。
7. 证据记录于 `docs/acceptance/2026-11-25/README.md`；列出环境、命令、版本、截图路径、实际结果及任何未覆盖项。截图与 HTML 可保留为本地 gitignored 文件。
8. 实现阶段新增可复用的 native acceptance 脚本，自动创建上述隔离 fixture；记录精确运行命令。验收记录保存第四轮预览文件的 SHA-256 和本地不可变副本路径，并附六组合对照截图，便于在同一工作区复现视觉基准。
9. 展示已通过测试和代码审查的构建，等待用户实机验收批准后再进行 commit/push。

### Design review

2026-11-25 独立只读审查指出 Stash 绕过普通 refs 绘制路径，已在方案及文件范围中补齐。同步明确极窄 `+N` 兜底、两种行高／15px 轨道／fork 测试、数值对比度断言和可复现的隔离配置失败场景。当前等待设计批准；尚未修改产品代码或运行实现测试。

## UI checklist

- 复用当前中性主题和 token，不增加渐变／装饰效果。
- 图标沿用现有库；间距、字号与测量统一。
- 使用真实 Git 引用和现有菜单；设置使用已有 hover、focus、选中态和键盘交互。
- 空仓库／加载／错误状态沿用现有界面；没有新增异步请求或动画。
- 检查选中背景与 hover 背景上的文本对比；小标签由整行与原有菜单承载操作，不缩小设置选项命中区。
- 本次为已完成预览的局部渲染与设置接入，复用第四轮 mockup；不重跑整页设计探索。实机视觉检查仍覆盖浅深主题、尺寸与字体缩放。

## Risks and rollback

- 主要风险：跨行接缝、选中光圈遮线、极窄／大字体时文字预算偏差、共享标签意外扩散；通过纯几何、测量回归和实机截图覆盖。
- 切换只重新绘制，避免不必要仓库 reload 或拓扑重建；如果现有缓存包含样式相关测量，只失效对应显示缓存。
- 回滚：撤销本功能提交并重建；旧应用忽略两个新 JSON 字段，Git 仓库与已有设置键不受影响。不删除用户配置。
