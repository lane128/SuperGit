## Background and goal

用户要求“这个 tab 也出一版设计”。目标是降低详情标签栏的视觉重量，让文件名、当前阅读目标与关闭操作容易辨认，同时保留鼠标可达的横向滚动。沿用现有 Git 工作台主题与密度，本轮只交付一套方向及边界状态。

现有实现事实：

- `history_panes.go:411` 使用 32 DIP 横向滚动容器、`KeepScrollbars(true)`。常驻滚动条是刻意保留的鼠标入口，并有 `TestHistoryDetailTabOverflowStaysVisibleAndDraggable` 保护，不能直接隐藏。
- `detailTabButton` 的 wrapper 最大 260 DIP；选中态复用 `paintWorkbenchTab` 的填充、圆角和描边，叠加加粗文字。截图中横向滚动条与标签内容距离很近。
- 文件名默认显示 basename，出现同名不同路径时显示完整路径；工作区标签必须保留 Staged / Unstaged；完整路径和版本在 tooltip 中。
- 概要 / 提交页不可关闭。文件标签按路径和 stage 去重；关闭选中项选择原位置的下一项，末尾选前一项，最后一个文件关闭后回到概要。
- 活动标签及其关闭按钮在打开、关闭和面板缩窄后必须揭示。方向键 / Home / End 及既有文件标签快捷键不能变化。

项目目标、用户和行为范围已从截图、前序会话及代码确定。本轮不进行外部竞品搜索，不增加产品发现问答，不申请付费设计生成。跨会话 brain cache 不可用，依据本地源码与已有设计记录完成。

## Proposed design

本地交互稿：`design/detail-tabs-redesign.html`。浅深色、SuperGit / Catppuccin、标准 / 1.15 字号、中英文、840 / 560 / 420 / 300 / 230 DIP 都是设计审核工具，不是产品新增设置。

### 布局与视觉

| 项目 | 提案 | 原因 |
| --- | --- | --- |
| 标签内容行 | `scaledFont(36)` DIP；预览提供 32 / 36 / 40 对比 | 比现有 32 DIP 增加 4 DIP，改善文字上下留白；标准字号含轨道总高 42 DIP，1.15 字号约 47.4 DIP |
| 滚动轨道 | 内容行下方独立 6 DIP，始终预留高度 | 不覆盖文字和选中标记；出现溢出时不让正文跳动 |
| 滚动滑块 | 默认 3 DIP 可见，高度在轨道 hover/focus 时为 6 DIP；交互命中整条 6 DIP | 保留鼠标可发现/可拖动，减轻视觉重量 |
| 标签字体 | 系统界面字体，`scaledFont(12)`，普通 400 / 选中 600 | 不用代码字体显示文件名；使用 600 测量宽度，选中不挤动邻项 |
| 状态徽章 | 18 DIP 空心徽章：4 DIP 圆角、1 DIP 同色边框、透明底；字母 `scaledFont(11)`、内置 Inter Bold（`SuperGit Status Text`，请求 800 时匹配 700）；A 绿、M/T 琥珀、D/! 红、? 蓝、R/C 紫、S 紫 | 保留既有状态字符和语义色分类；空心描边让字母更醒目，又不增加一排实色色块；固定字面让字母不随代码/界面字体变化，并与 Files 标记共用 |
| 普通标签 | 与标签栏同底色，次级文字，末尾轻分隔线 | 减少按钮盒子的感觉 |
| 当前标签 | 正文底色、正文文字、2 DIP 主题强调色底线 | 颜色和形状共同标记选中，不依赖大面积蓝底 |
| 悬停 / 按下 | 沿用现有中性 Fill token；键盘焦点有独立 2 DIP 焦点框 | 焦点与选中不是同一种状态 |
| 历史文件最大宽度 | `scaledFont(240)` DIP，且不得大于当前视口 | 长名字不独占整行 |
| 工作区文件最大宽度 | `scaledFont(280)` DIP，且不得大于当前视口 | 额外容纳完整 Staged / Unstaged |
| 关闭按钮 | 24 DIP 固定宽度 × `scaledFont(30)` DIP 高度，12 DIP Lucide X，始终显示 | 不因 hover 增减槽位；关闭按钮不被名称挤走 |
| Summary / Commit | 仍为第一个标签、参与原有滚动、不可关闭 | 不引入固定标签行为 |

颜色优先从现有主题 Tokens 获取，状态语义遵循 `statusTagColor`。空心徽章的文字和描边为详情标签局部样式：A/M/D 字母与描边对标签正文底色、栏底和 hover 底色均 ≥7:1，其余状态 ≥4.5:1。描边使用当前文字色，不额外引入低对比边框。现有 token 不足时只调整详情标签局部颜色，不修改全局状态色。仅为 detail strip 定义局部样式；不能修改共享 `paintWorkbenchTab` 而改变顶部仓库标签。

根据用户本轮反馈，推荐 36 DIP：32 DIP 更紧凑，40 DIP 更宽松；36 DIP 在辨认徽章、点击关闭和保留 diff 阅读空间之间更均衡。预览“状态颜色示例”使用明确的示意文件展示 A/M/D/R/?/S，状态样式、颜色与高度控件只用于设计比较。

### 状态字母与对比内容

用户反馈上一版状态色仍不够醒目，先要求做成带描边的 icon 样式，随后确认空心效果更好。本轮将状态改为 18 DIP 的空心徽章：4 DIP 圆角、1 DIP 同色描边、透明底；字母为 11 DIP / 800。文件名继续为 12 DIP / 400（选中 600），保持徽章与文件名的字重差异。浅色主题使用深色字母与描边，深色主题使用亮色字母与描边；A/M/D 字母和描边对标签背景目标为 7:1。

徽章只占 18 DIP 高，位于 36 DIP 标签行内，不改变行高。选中只改变标签底色、文字层级和底线，不改变徽章的颜色或描边。预览提供“空心描边 / 仅字母”比较项，默认空心；这是设计审核工具，不新增产品设置。

| 字母 | 含义 | 当前对比中应呈现的内容 |
| --- | --- | --- |
| A | Added / 新增 | 对比左侧无该文件，右侧为新增内容 |
| M | Modified / 修改 | 同一文件的修改前后；可能包含增加行、删除行或两者 |
| D | Deleted / 删除 | 对比左侧为原文件，右侧无该文件 |
| ? | Untracked / 未跟踪 | 工作区中尚未纳入 Git 跟踪的文件，不等同于已暂存新增 |
| R / C | Renamed / Copied，重命名 / 复制 | 路径变化，并可能伴随内容修改 |
| T | Type changed / 类型变更 | 文件类型变化 |
| ! | Conflict / 冲突 | 沿用应用现有冲突优先标记 |
| S | Submodule / 子模块 | 沿用应用现有子模块标记；并非普通文件状态 |

源码 `statusCode` 对冲突和子模块优先显示 ! / S，其余按当前 Index / Worktree 侧选择状态。字母应与当前比较范围对应：已暂存为 HEAD → Index，未暂存为 Index → Working tree；历史比较按原有提交范围处理。实现仍沿用这一逻辑，不从示例文件名推断状态。完整悬停说明/辅助功能名称包含状态字母和含义。

HTML 原先所有文件共用同一段新增行示意，本轮改为 A 全新增、M 修改前后、D 全删除，且明确标注“示意对比”。这是演示内容，不是读取仓库的实际 diff。

### 名称与版本

- 超长名称使用 Unicode 安全的中间省略，优先保留开头、末尾及扩展名；字符串切分至少以完整 Unicode 字符为单位，不能破坏 UTF-8。对于组合字符，以可见字素为单位处理或使用 MyGo 现成文本截断能力；若现有能力仅支持尾部省略，实施前明确技术方案，不能以乱码完成视觉稿。
- 同名不同目录保留当前完整路径的语义，不引入新的“最短唯一父目录”算法。可视文本中间省略，tooltip 与辅助功能名称保留完整路径。
- 暂存状态仍是文本后缀 `· Staged` / `· Unstaged`、`· 已暂存` / `· 未暂存`，不可省略，不只靠状态字母 M 区分。
- 不改变文件身份、路径、去重、排序、上下文缓存或 diff 阅读目标。截断只影响绘制文本。
- 230 DIP 压缩视口下先收缩名字，保留版本后缀和关闭按钮。需要验证大字号英文 Unstaged 场景；若仍不能容纳最小名称、版本和关闭槽，应报告尺寸限制而不是隐藏操作。

### 溢出与操作

- 不换成两行 tab，不提供额外菜单、左右箭头、固定、重排、批量关闭等功能。
- 横向手势、Shift 滚轮、鼠标拖动滑块沿用滚动机制；拖动只改变偏移，不切换活动文件。
- 无溢出时隐藏滑块，但保留 6 DIP 空轨道。溢出时指针不在标签栏内也要看得到滑块。
- 打开标签、键盘切换、关闭选中项和缩窄面板后，揭示当前标签及完整关闭按钮；可见项不无谓跳到居中。
- 将焦点从关闭按钮交回其继任标签，遵守现有焦点恢复与 Tab / Shift+Tab 行为，不新增键盘绑定。整个 strip 保持一个 Tab 停靠点，下一次 Tab 离开组、Shift+Tab 回到活动项；关闭按钮和滚动轨道不增加 Tab 停靠点，方向键/Home/End 仍由原标签组处理。
- 文件隐藏、Summary 隐藏、加载中和操作 busy 的权限/可用性由现有逻辑决定。只有概要时没有关闭按钮和滚动滑块。

## Alternatives and trade-offs

| 方案 | 覆盖和代价 | 结论 |
| --- | --- | --- |
| 最小改动：保留圆角按钮，只降低选中底色并缩细滚动条 | 改动最少，但活动文字/边框/滚动条仍集中在同一窄行 | 备选，不作为本稿主方向 |
| 推荐：平面标签、独立滚动轨道、稳定名称与关闭槽 | 局部结构调整；标准字号总高 42 DIP，比现有 32 DIP 容器增加 10 DIP；需要补滚动/尺寸回归 | 本稿展示，等待用户审核 |
| 固定 Summary + 箭头 / 全部标签菜单 | 可提升大量标签跳转，但新增可见操作与焦点模型 | 超出本次范围，不实现 |

用户随后以“按照这个版本修改”批准空心描边、36 DIP 内容行的完整方向，进入实现。

## Impact

- 预计产品修改：`history_panes.go` 内详情标签栏及局部样式/名称绘制 helper；视框架支持情况新增 `detail_tab_style.go` 或局部滚动轨道 helper。
- 相关验证：`detail_tab_caption_test.go`、`detail_tab_close_reveal_test.go`、`detail_tab_stop_test.go`、`detail_focus_test.go`、`file_tab_shortcut_test.go`、`detail_tabs_test.go`、`button_style_test.go` 与 `scripts/native-detail-tabs-smoke.py`。
- 空心徽章可行性：MyGo 现有绘制需支持局部圆角矩形、1 DIP 描边和居中文字，且描边内保持透明；实施前先核对 `ui` 的圆角/描边原语与文字基线。若框架只能绘制实色填充或无圆角边框，先报告并调整视觉，不擅自把徽章做成字符背景或修改全局组件。
- 共享框架可行性：MyGo `ui/scroll.go` 提供可写的 ScrollState 偏移与实测边界；`ui/scrollbar.go` 的标准绘制使用主题宽度、固定底边 inset 和拖拽扩张，不能直接表达本稿全部 3→6 DIP 几何。因此实施前必须先验证局部轨道绘制与命中，同时保留原生 wheel、offset clamp、TrackScroll 和 ScrollIntoView 语义；不可同时留下两条可操作轨道。优先包装局部滚动容器，不改 vendor 或全局滚动条 token；若需要共享框架变更，先更新设计并说明范围。
- 不涉及 Git 写操作、持久化格式、设置开关、更新签名、安装或仓库 tab。

## Acceptance steps

1. 视觉与几何规则已批准。实现后先完成测试与独立代码审查，再进行以下原生验收。
2. 实施后 `make app`，在隔离 HOME/仓库复现截图中的四个标签，包含两主题/两字号以及 SuperGit/Catppuccin。
3. 连续打开 12 个长文件名，缩窄详情分隔栏，鼠标拖滚动条，切首尾标签，检查活动名称、版本和关闭按钮可达。
4. 同一文件打开 Index/Worktree 两个版本，再关闭活动项并回概要，检查实际差异与焦点没有错位。
5. 截图同时记录视口/标签/滑块/关闭按钮的 DIP 边界。HTML 只证明设计稿，不替代 MyGo 原生渲染。
6. 原生证据记录在实施当天的 `docs/acceptance/`。构建和运行本地 bundle；安装、提交和发布不在本次实现授权内。

## Risks and rollback

- 滚动条缩细可能降低可发现性，必须保留静置可见和完整命中轨道；不能为截图好看删除原有可达性测试。
- 字重、字体族、DPI 与大字号影响测量，需测量当前界面字体的 600 weight，避免活动项宽度跳变。
- HTML 的 scrollbar 仅模拟原生机制。MyGo 的绘制与命中能力尚待实施前核对，可能需要局部自绘，而非全局样式覆盖。
- 回滚仅撤销详情标签栏样式/局部布局和配套测试，保持现有文件/暂存版本状态模型。
