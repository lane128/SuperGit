# 通知标题行对齐

截图中的「已复制」提示实际使用两层顶部对齐的 Row，并给图标单独增加了 5 pt 顶部间距。因此状态图标、标题、关闭按钮没有共同的垂直中心。

设计：单行消息以原有关闭按钮高度为标题行的最小高度。状态图标和标题在这段高度内各自居中，横向留白、卡片宽度和关闭按钮尺寸不变。长标题允许换行，状态图标与关闭按钮保留在卡片上部；描述和操作不参与标题对齐。共享渲染覆盖主窗口与设置窗口，不改变超时、堆叠、进度或操作行为。

验证：独立像素回归在旧版测出「已复制」文字比关闭按钮中心高 6.5 pt；修正后中英文单行及长文换行测试均通过。隔离剪贴板的渲染测试通过实际复制成功通知入口生成[提示截图](../../build/qa-notice-header.86P7f8/copied.png)，标题行框与关闭按钮中心同为 y=77.5 pt。最终安装包通过深度严格签名校验，二进制与构建产物相同；同源原生窗口再次验证 Summary 三段中心距均为 26 pt，复制按钮 24 × 24 pt，两个父链接目标正确。
