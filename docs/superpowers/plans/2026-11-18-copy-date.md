# Copy Date

**Status:** Implemented; actual-click RED→GREEN, focused race and independent static review completed. Whole ordinary suite and vet passed for the 511-input snapshot. Later lifecycle tests are recorded separately below. No commit, installation or publication.

**Goal:** Add the date's existing Sublime Merge menu capability with a small read-only context action.

## Scope and evidence

The installed Sublime Merge Build 2125 `Default.sublime-package/Commit Date.sublime-menu` declares `Copy Date`, command `copy_to_clipboard`, argument `text: $date`. Product inspection found no reliable definition of the generated `$date` string. Resource declarations do not establish native output parity.

Implementation decision: copy the complete currently displayed author date, using existing `formatDateTime(commit.Date)`. RFC3339 values become local `YYYY-MM-DD HH:mm:ss`; invalid values retain their displayed original text. This preserves existing display behavior, including its omission of timezone offsets. Exact Sublime native copy formatting remains unverified. No new format setting or alternate date source.

## Implementation and verification

- Attach one Copy Date / 复制日期 action to the existing date element, preserving layout and existing author menu.
- Capture the full display value while closed and freeze it while open. Empty values disable copying. Reuse `copyText` feedback without repository work, selection or draft changes.
- Actual right-click/menu-click tests cover both languages, RFC3339 local conversion with seconds and cross-day input, unparseable displayed text, long author at maximum font in 480×360, refresh while open and clipboard failure.
- Add cancellation/empty-value checks; verify the old author menu remains independent.
- Run focused race, independent review, whole ordinary suite and vet with source fingerprints. Native clipboard and OS runtime acceptance remain separate.

Three independent worktree roles supplied product/resource research, design review using Emil Design Engineering and Impeccable, and test-boundary review. All were read-only; main implements in the integration checkout.
