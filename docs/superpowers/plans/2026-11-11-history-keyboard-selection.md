Goal: make loaded history a keyboard-selectable virtual list with correct filtered SHA selection and retained identity across refresh. Use MyGo's existing single-selection/scrolling semantics instead of global unmodified arrows.

Design: a presentation-bound history cursor tracks selected visible row, prior immutable model and selected SHA. Synchronize it only when model or selected SHA changes, leaving fresh list input intact on repeated frames. Bind ListState.Selected to cursor row and Key to immutable model SHA. Changed chooses that row through a guarded mapping to the current snapshot's original index; Submitted reloads that commit's details, never executes Git writes. Mouse row buttons keep existing behavior and return focus to the list. Cmd+2 explicitly focuses the commit list; Cmd+F focuses search; search's Enter transfers focus into results without clearing query, Escape also returns to results preserving query. After repository switch reset list/cursor/focus flags. Filter changes keep hidden selected detail but no matching row is selected until explicit user input. Old presentation callbacks and write/open states cannot select a stale row. Background snapshot reading leaves immutable-current-model browsing available. Existing parent/boundary/DAG and 2,000 cap remain unchanged.
