# Commit File Keyboard Navigation

Directive: continue the complete Git GUI product via dynamic /loop. Inline work in the existing non-Git workspace. No project commit/publish, user repository writes, or external services. One narrowly scoped read-only review.

Goal: native virtual single selection for immutable commit changed files, accurate SHA/path Diff, focus transfer from/to commit history, stale callback rejection and independent workspace state.

Design: immutable presentation cached by repository generation, selected SHA and commit-file revision. Copy changed-file records. Cursor reconciles model/path only when external identity changes; callbacks validate the current model, SHA, source record and page/write/open state. Replacement file reads increment revision, never reset live ListState from callbacks. File list resets during view construction on presentation replacement, preserving Handle and only restoring its own focus. Use existing cancellation/read lane for file Diff. Cmd+Right from history list focuses changed files; Cmd+Left from files returns to history. No global arrows or write shortcuts. Enter reloads the current file Diff. Normal commit auto-selects its first file; empty commits have no selection. History Diff scroll reset is also deferred to diffView, so async file reads cannot invalidate a committed accessibility tree.

Layout: preserve commit metadata, parents and action buttons in a bounded scroll region (180 DIP); changed files occupy the remaining details area, with a virtual viewport. Increase initial/reset details height to 340 DIP to keep both metadata and files usable; divider remains adjustable.
