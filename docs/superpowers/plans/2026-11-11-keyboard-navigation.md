Goal: make existing pages and history search accessible from the keyboard, prevent hidden workspace commits from other pages, and reset Diff scroll/preview when an automatic refresh changes its file/group target.

Investigation: view currently handles Cmd+O/R/Enter globally; canCommit checks staging/draft/busy but not the visible page. A history/action/conflict editor can therefore commit unrelated workspace staged content with Cmd+Enter. The file reconciliation routine changes path/group before reloadDiff(preserve=true), so the subsequent equality check retains the previous preview/scroll. Also showCommitFile resets workspace diffList instead of historyDiffList.

Design: Cmd+1…9 select existing sidebar pages in their current order. Cmd+F focuses the history search on the history page only. Cmd+O/R retain existing behavior outside action forms; Cmd+Enter commits only from the workspace with existing Index/conflict/busy guards. Escape cancels an idle action form/confirmation, sharing the existing cancel-button path; it never executes a confirmation or cancels a Git process. All navigation/open/refresh shortcuts pause on action pages; navigation pauses during writes/opening, and held-key repeats do not invoke commands repeatedly. Plain typing and text editing keys remain owned by MyGo. Shortcut hints use existing control tooltips and accessibility metadata; no new settings or screens. Reconcile target changes clear selection, prior preview and workspace list state; stable targets preserve selection/scroll. Historical file changes reset only the historical list.
